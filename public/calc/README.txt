CALCULATOR BACKGROUND IMAGES — drop zone
========================================

Each calculator in the Power-Up section has a bento "image" card. Drop a
nature / glossy / soft-blurred image here with the matching name and it will
appear automatically (a gentle teal gloss overlay is applied for depth):

  public/calc/compound.jpg     → Compound Growth calculator
  public/calc/super.jpg        → Superannuation calculator
  public/calc/retirement.jpg   → Retirement Needs calculator
  public/calc/mortgage.jpg     → Mortgage calculator
  public/calc/tax.jpg          → Income Tax calculator

Guidance
  • Format: .jpg (or rename the slot keys if you prefer .png/.webp)
  • Suggested size: ~1200 x 700, landscape
  • Style: calm, on-brand — greenery, coastline, soft light; pre-blurred works well
  • Until a file is present, the card shows a dashed "Drop image here" placeholder.
